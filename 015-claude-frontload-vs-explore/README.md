# #015 Front-load context vs let it explore (Claude Code CLI)

**Question.** If you hand Claude Code the file path, the check command and the file contents up front, instead of a bare bug report, how much do you save?

**Short answer.** On 6 bugs × 2 reps (24 runs, all passed), front-loading cut **total tokens 45%** (78K → 43K mean) and tool calls from 3.3 to 1.4 per task, but cut **API-equivalent est. cost only 13.5%** ($0.118 → $0.102). Most of the tokens it saved were cheap cache reads ($0.20/M) of the ~11–16K system prefix on each extra model call; the pasted files themselves land as new cache writes ($8/M). Savings were biggest where the bare run had to hunt (N01 −35%, N02 −27%) and ~0 on N03/T05, where the model still ran the test a couple of times. Claude Code never used its Read tool to explore: it explored with Bash (`ls`, `cat`, `grep`), so "read calls" here are Bash calls.

## Setup
- Claude Code 2.1.300, `claude-opus-5-5`, default effort, Pro sign-in; headless `claude -p … --output-format stream-json --verbose --dangerously-skip-permissions --strict-mcp-config --no-session-persistence`, fresh temp copy of the full 14-package `SUITE14` fixture per run (13 packages broken, so the bare arm has to find the right one).
- 6 target packages: N01_median, N02_duration, N03_csv, T05_stale, T07_multihunk, T10_replace_all. Pass = `cd <pkg> && node test.js` exits 0 and no test.js/run_all.js changed.
- **bare** arm: "This folder holds 14 small JavaScript packages. Bug report: <symptom>. Find the package and fix its code…" (no path).
- **frontload** arm: same symptom + "The bug is in `<pkg>/broken.js`. Check with `cd <pkg> && node test.js`" + the full broken.js, test.js (and any helper file) pasted in. Prompts in `scripts/prompts/`, generated by `scripts/make_jobs.py`.
- 2 runs at a time, 2026-10-14 ~19:47–19:51 UTC. Est. $ = Claude Code's `total_cost_usd` (list API price) — **API-equivalent estimate; Pro isn't billed per token.**

## Exact commands

## Caveats
- Tiny packages (≤1.3 KB files). In a big repo the bare arm would read much more, so the saving here is a floor; equally, pasting big files would cost more cache writes.
- The front-load prompt also names the check command; I didn't separate "path" from "contents" from "command".
- 2 reps per cell; Claude's run-to-run variance is ~1% (#010b), so the arm differences are real for these tasks.
- The cited "reads are 76% of agent tokens" can't be checked directly: Claude explored via Bash, and its per-call context is dominated by the system prefix, not file reads.
